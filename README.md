## Project Overview

This project implements a **Digital Stethoscope** using the **LPC2148 ARM7 microcontroller** for capturing, amplifying, processing, and visualizing heartbeat sounds.

Unlike traditional stethoscopes that provide only audio feedback, this system digitizes heart sound signals and displays real-time heartbeat waveform on an OLED display.

The system is designed as a low-cost biomedical instrumentation solution for heartbeat monitoring and educational healthcare applications.

---

## Objectives

- Capture heartbeat sounds using microphone  
- Amplify weak heartbeat signal  
- Filter noise using analog filter circuit  
- Digitize signal using LPC2148 ADC  
- Display waveform on OLED display  
- Provide audio output through speaker  

---

## Hardware Components Used

- LPC2148 ARM7 Microcontroller

- OLED Display (I2C)

- Resistors and Capacitors
